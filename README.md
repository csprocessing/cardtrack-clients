# CardTrack API clients

Official clients for the [CardTrack Price API](https://cardtrack.com/developers): Pokémon card prices, English and Japanese, raw and graded.

| Language | Package | Folder |
| --- | --- | --- |
| JavaScript / TypeScript | `npm install cardtrack` | [js](js) |
| Python | `pip install cardtrack` | [python](python) |
| Postman | collection | [postman](postman) |

Get a free key at [cardtrack.com/developers](https://cardtrack.com/developers). OpenAPI spec: https://cardtrack.com/api/v1/openapi.json
